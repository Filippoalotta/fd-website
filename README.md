# Political Presence

Crea la homepage per una figura politica e istituzionale. Il design deve essere moderno, autorevole, arioso e minimale. Usa Tailwind CSS. Colori principali: blu navy molto scuro (primario), accenti azzurri eleganti e molto spazio bianco. Tipografia: font sans-serif geometrico e pulito. La pagina deve avere:

Una Navbar pulita.

Una Hero Section con spazio per una foto ritratto a destra, un titolo forte a sinistra ("La mia esperienza in Europa"), una breve bio e un pulsante 'Scopri il libro'.

Una sezione 'Ultimi Aggiornamenti' con un layout a griglia (3 colonne) contenente card eleganti per i comunicati stampa. Le card devono avere ombreggiature leggerissime.

Una sezione 'Iscriviti alla Newsletter' con un design pulito.

Un footer istituzionale.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
